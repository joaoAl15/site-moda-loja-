Configurações do repositório
Como conseguir a chave de acesso?
  1. Entre no GitHub com a conta onde o site está publicado.
  2. Abra github.com/settings/personal-access-tokens/new.
  3. Dê um nome (ex.: Painel Loja de Moda) e escolha a validade.
  4. Em Repository access, marque Only select repositories e escolha só o repositório do site.
  5. Em Permissions → Repository permissions → Contents, escolha Read and write.
  6. Clique em Generate token, copie e cole no campo acima. Não compartilhe essa chave.
